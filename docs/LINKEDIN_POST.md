## English post

I built a game to learn how AI agents actually work. 🎮🤖

**BIT-7 Facility Escape** is a 12-level pixel puzzle game. You never control the robot directly. Like an AI engineer, you give its LLM brain tools (MCP servers), write its mission, and watch it reason, search documents and act on its own.

Every level is built around a problem real AI teams face:
🔧 Tool use: an LLM can't do anything without tools
📚 RAG: the archive holds both the current code and an outdated one
🧭 Embeddings: “storeroom” ≈ “warehouse”, but keyword search can't tell
🛑 Prompt injection: a document tells the AI to pull the alarm fuse
🛡️ Guardrails: mask customer NRIC and card numbers before a report leaves
⚙️ Workflow vs agent: a Power Automate-style flow breaks when the code rotates
🗄️ Vector databases: filter and rerank 2,000 near-identical documents
…plus memory, multimodal, multi-agent, tool design and evals.

It's picture-first: a live flow diagram shows every message moving between the LLM, the tools and the robot. There's a 16-question knowledge check at the end. My score: __/16.

Free, open source, a single HTML file, and available in English and 中文.

🧭 Embedding：“储藏室”≈“仓库”，关键词检索却分不出来
